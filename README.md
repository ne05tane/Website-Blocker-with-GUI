## How To Run 

1. Clone repo or download folder
```
git clone <your-repo-url>
cd <your-repo-folder>
```

2. Run the Executable

     Windows: double-click main.exe <br> Mac/Linux: If you compiled for these, run ./main in the terminal (might need sudo).

#### Since this blocks websites, it needs admin rights. Right-click main.exe and select "Run as Administrator", or it won’t be able to edit your hosts file.
#### If your antivirus flags main.exe, it’s a false positive (common for apps that edit system files). You can either add an exception or run the .py file directly if you have Python installed.
